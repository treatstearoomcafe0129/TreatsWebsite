# Treats Tea Room Café — website

Source for the Treats Tea Room Café website, 10–11 Silver Street, Durham.

The site is a single bespoke WordPress theme, written from scratch. The
previous Enfold build is not used, extended, or referenced anywhere in here.

```
treats-tea-room/    The theme — copy into wp-content/themes/
```

Full documentation, install steps, and the pre-launch checklist are in
[`treats-tea-room/README.md`](treats-tea-room/README.md).

## Quick start

```bash
# From a WordPress install
cp -r treats-tea-room /path/to/wp-content/themes/

# Or build an uploadable zip
zip -r treats-tea-room.zip treats-tea-room -x "*.DS_Store"
```

Activate **Treats Tea Room** under *Appearance → Themes*. The theme scaffolds
every page, navigation menu and starter menu item on first activation, then
never touches your content again.

## What is in the theme

- Home, five menu pages, Book a Table, Gift Vouchers, About, Contact, FAQ,
  Gallery, Journal, Privacy and Accessibility
- Sticky navigation, animated scroll reveals, interactive filterable menus,
  Click & Collect, online booking, gift voucher orders, reviews, gallery
  lightbox, Instagram feed, click-to-load Google Maps, contact forms and
  newsletter sign-up
- Dark mode, WCAG 2.2 AA orientation, JSON-LD schema, self-hosted fonts,
  conditional assets, no jQuery on the front end
